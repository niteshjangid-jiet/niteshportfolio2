# 🚀 Nitesh Jangid - Modern Developer Portfolio

Welcome to the official repository of my personal portfolio website! Built with modern web technologies, this portfolio showcases my software development projects, technical skill set, academic journey (2024–2028), and achievements in a clean, responsive dual-theme design.

---

## ✨ Features

- 🌓 **Dual-Theme Support**: Instant switching between Light Mode & Dark Mode with clean typography and optimized visual contrast.
- ⚡ **Performance-Optimized**: Built with Vite + React 18 + TypeScript, ensuring lightning-fast load times and smooth page transitions using Framer Motion.
- 💻 **Project Showcase**: Full-featured project grid highlighting live demo links and tech details.
- 🎓 **Academic Journey & Experience**: Interactive timeline illustrating my B.Tech CSE education (2024–2028) and practical project milestones.
- 📱 **Fully Responsive**: Flawlessly adapts across Desktop, Tablet, and Mobile viewport screens.

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 18 with TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons / Lucide Icons
- **Routing**: React Router DOM

## 🚀 Getting Started Locally

To run a copy of this project on your local environment:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### 1. Clone the repository
```bash
git clone https://github.com/niteshjangid-jiet/niteshportfolio.git
cd niteshportfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run local dev server
```bash
npm run dev
```

Open `http://localhost:5173` in your browser to view the application.

### 4. Build for production
```bash
npm run build
```
